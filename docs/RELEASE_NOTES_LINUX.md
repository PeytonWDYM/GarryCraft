Linux x64 and single-player 64-bit Garry's Mod are required. Own Garry's Mod and Minecraft Java Edition.

1. In Steam, select Garry's Mod > Properties > Betas > x86-64.
2. Wait for the update, then close Garry's Mod.
3. Download **GarryCraft-{version}-linux-x64.zip** below. Use this asset, not the Source code archives.
4. Extract the entire ZIP and open **install.sh**.
5. Open the printed **play.sh** path and select Sandbox > gm_construct > Single Player.
